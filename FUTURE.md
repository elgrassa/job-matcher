# Future Features (Out of Scope for v1)

These features have been explicitly deferred. Do not implement them in v1.

- **Auto-apply**: Automatically submit applications via platform APIs or browser automation
- **CV generation**: Generate or tailor CV content using LLM
- **Form filling**: Auto-fill application forms on job platforms
- **Notion/Airtable sync**: Export job state to external project management tools
- **Slack/email notifications**: Push alerts for high-scoring new jobs
- **Embedding-based scoring**: Use vector embeddings as a third scoring signal
- **PLN/CHF/GBP currency conversion**: Rate floor checks for non-EUR currencies
- **Fuzzy dedup**: Levenshtein or ML-based duplicate detection beyond exact canonical ID
- **Multi-user support**: Shared state, auth, or concurrent user access
- **Web UI / dashboard**: Browser-based interface (CLI is sufficient for v1)
- **Resume parsing**: Extract structured data from PDF/DOCX CVs (we use markdown)
- **Company research**: Glassdoor/LinkedIn company data enrichment
- **Interview tracking calendar**: Calendar integration for interview scheduling
- **Salary negotiation assistant**: LLM-powered salary negotiation guidance
